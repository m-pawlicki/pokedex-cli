# Pokedex

Explore the world of Pokemon, search for them, and try catching them to add them to your Pokedex!
Many thanks to the [PokeAPI](https://pokeapi.co/) for making this possible.

# Usage

`go install pokedex-cli`

# Commands

`exit`
> Exit the Pokedex

`help`
> Displays this help message

`map`
> Displays the next 20 locations

`mapb`
> Displays the previous 20 locations

`explore <area-name>`
> Explore an area for Pokemon

`catch <pokemon-name>`
> Try to catch a Pokemon

`inspect <pokemon-name>`
> Inspect a caught Pokemon

`pokedex`
> View your Pokedex
